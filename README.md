# Solopova Makeup — maketa spletne strani (mockup)

Večstranska statična stran, 3 jeziki: slovenščina (privzeto), angleščina, ruščina.

## Kako odpreti
Odpri `index.html` v brskalniku (ali poženi lokalni strežnik v tej mapi).

## Datoteke
- index.html, storitve.html, galerija.html, tecaj.html, kontakt.html
- assets/style.css, assets/i18n.js

## Kaj zamenjati
- Sive/svetle plošče (razred `.ph`) zamenjaj z resničnimi fotografijami.
- Besedila so v `assets/i18n.js` (ključi po jezikih).
- Cene (`.price`) so trenutno skrite/placeholder — dodaj svoje.
- Socialne povezave: header/footer (dodaj Instagram/WhatsApp, ko bodo znane).
- Domena: predlog solopovamakeup.si (kasneje).

## Opomba
To je prva maketa. Design in vsebino prilagodimo.
